# 🎵 Python Music Playlist

A simple music playlist manager made in Python using a Doubly Linked List.

## ✨ Features
* **Add Songs:** Add new songs to the playlist.
* **Delete Songs:** Remove any song from the list.
* **Navigation:** Move to the next or previous song easily.
* **View Playlist:** See all songs in order.

---

## 🚀 Getting Started

To run this project on your computer, follow these steps:

**Step 1: Clone the repository**
```bash
git clone https://github.com/withilq/Python-Music-Playlist.git
cd Python-Music-Playlist
```

**Step 2: Run the script**
```bash
python playlist.py
```
